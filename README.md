# Man Mandir Jewellers 

A premium, cinematic, frontend-only showcase website built for luxury Indian jewelry. Developed with React.js, Tailwind CSS, and Framer Motion, it features an Awwwards-winning "Dark Mode Apple" aesthetic with heavily rounded glassmorphism cards, custom cursor interactions, and smooth scroll-driven animations.

## Live Demo
Run it locally to experience the cinematic animations.

## Features
- **Aesthetic**: Deep Midnight Blue, Champagne Pearl text, and Metallic Gold accents.
- **Animations**: Scroll-driven Framer Motion reveals, parallax scrolling, custom interactive cursor.
- **Layout**: Floating dark-glass cards (`ios-card`), asynchronous masonry grids, and horizontal scroll sections.
- **Routing**: Full React Router SPA implementation including Home, Collections, High Jewelry, Bridal, and The Maison (About) pages.
- **No Backend**: Pure frontend showcase designed for speed and visual excellence.

## Tech Stack
- **React 18** (Vite)
- **Tailwind CSS 3** (Custom global styling and PostCSS)
- **Framer Motion** (Animation engine)
- **React Router Dom** (Navigation)
- **React Icons** (SVG Icons)
- **Vanilla JS & CSS3**

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/codewitharyan-01/jeweler-website.git
```

2. Install dependencies:
```bash
cd jeweler-website
npm install
```

3. Start the development server:
```bash
npm run dev
```
